Правила для My Collection
Добавление
Без названия сохранить предмет нельзя.
Строка из одних пробелов считается пустой.
Фотография и описание необязательны.
После успешного сохранения открывается карточка.
Если сохранение не удалось, введённые данные остаются в форме.
Редактирование
Форма открывается с текущими данными.
Можно изменить название, описание и фотографию.
Можно удалить фотографию, не удаляя сам предмет.
Отмена не изменяет сохранённую запись.
Удаление
Перед удалением появляется подтверждение.
В подтверждении указано название предмета.
Кнопки: «Отмена» и «Удалить».
После удаления открывается каталог.
В первой версии корзина и восстановление не предусмотрены.
Поиск
Поиск работает только по названию.
Регистр букв не учитывается.
Достаточно совпадения части названия.
Пустой запрос показывает все предметы.
Поиск ничего не изменяет и не удаляет.
Выход из формы
Если изменений нет, форма закрывается.
Если есть несохранённые изменения, приложение предлагает остаться или выйти без сохранения.
